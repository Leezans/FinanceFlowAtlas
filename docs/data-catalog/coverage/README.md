# FinanceFlowAtlas 全球股票资金来源准备矩阵

核查日期：2026-11-04。交付是**覆盖普查骨架、实际小范围获取证据、接入队列**，不是“所有国家数据已接好”。本目录仅发布研究覆盖元数据，不包含原始观测金额或数据响应。

## 可直接使用的文件

- `country-readiness.csv` / `.json`：250 个国家/地区逐一记录。分母为系统 ISO 3166-1 名录的 249 项，加单独列出的 Kosovo（XKX，非正式 ISO 分配）；包括属地，不等于 250 个主权国家。
- `national-source-registry.csv` / `.json`：从项目已核验目录提取的 24 个国家级/交易所来源，涉及 22 个经济体。官方链接、口径、频率、限制分别保留。目录 V1 不是本轮接口实测。
- `coverage-summary.json`：按证据范围统计的数量。

## 已证实的范围

**IMF BOP 真实交易数据**：2024–2026，年/季频，USD，资产净取得 A_NFA_T、负债净发生 L_NIL_T。

- `P_F51`（证券投资股权）：93 个经济体在该查询范围内至少有一个数值观测。原始 95 个报告代码中排除 `CWX`（Curaçao 和 Sint Maarten 合并项）、`G163`（欧元区）。
- `P_F5`（股权及投资基金份额）：169 个经济体；原始 172 代码另包含前述两个和 `G309`（东加勒比货币联盟）。该项不能标作纯股票。
- 两项可重叠，不能相加成国家数或金额。一个国家有一个时期/方向的数据，不代表所有季度和双向均有数据。矩阵保留全部可用时期、频率、方向。
- 新发现 dataflow `IMF.STA:BOP(21.0.0)`，DSD `24.0.0`。请求带 `format=csvfile`，服务实际返回 XML；保留真实 XML，适配器应以响应类型/内容解析，不能盲信文件扩展名。
- 单位 USD、SCALE=6 均来自原始元数据。这里不假设 SCALE 必须乘 10^6；货币归一化需另做系列级官方表对账。

**IMF PIP 股权头寸**：审计既有 PIP 2025-S2 源文件（内容哈希见 coverage-summary.json，原始文件不随仓库分发），不是本轮重新下载。

- 与现有适配器严格 ISO 代码、非本国、非负、未标保密/缺失筛选完全对齐时：12,501 条边，79 个报告经济体，237 个对手经济体。
- 本矩阵研究性加入明确代码对照和 Kosovo 后：12,886 条边，80 个报告经济体，240 个对手经济体。不是现有适配器新增接入，也不应替换其运行计数而不修改和测试映射。
- 对手国出现仅表明他国持有该地发行证券，不表示该国主动报送。PIP 是头寸，不是净资金流。真实零保留，缺失与保密绝不填零。
- 较早 `imf-pip-2025-s2-compact.json` 有不同记录数，不作为当前矩阵依据。两文件不是相同范围，不能混报。

**国家来源研究**：22 个经济体有既有目录产品证据，23 个经济体仅列待验证机构候选，205 个尚未做国家源研究。后两类仍可有 IMF 数据；不得把“国家源未研究”解释成“该国没有数据”。

## 状态的严格含义

- `numeric_observations_present`：这次明确范围内存在数值，不代表全历史/全字段/生产可用。
- `not_returned_in_2024_2026_query` / `not_observed_in_selected_snapshot`：此查询/快照没有记录，不是已证明全球不存在数据。
- `candidate_not_verified`：候选机构，未验证具体产品/API。
- `not_researched`：尚未研究国家级来源。
- `restricted`：明确限制，必须先取得许可。B3 不可自动采集；TWSE 目录产品的外部使用不等于公共披露许可。
- `unknown` 权利：没有获得肯定许可，不能自动当作允许公开展示/下载。
- 所有行 `production_readiness=not_certified`：本轮没有完成应用接入、完整质量/许可验收、部署。

## 接下来按什么顺序落实

1. 将 IMF BOP 现行结构与有值覆盖作为国家层真实交易基线。分别建纯股权、股权+基金两种指标，不混接。
2. 校验金额单位和符号，资产流出/负债流入方向，BPM6/BPM7、年季数据重复、修订及发布时点。先做几个国家和官方表的对账再接 UI。
3. 对已有 PIP/TIC 保留既有实现证据；新增代码映射需先测试。对 PIP 无值的国家可展示“仅作为对手方”或明确缺口。
4. 再按既有目录接 TIC、加拿大、日本、印度等。国家交易所统计与 BOP 不能相加成统一全球净流。
5. 对未研究经济体先做 IMF 缺口及官方央行/统计机构目录核对，再考虑交易所授权。没有公开市场不等于证券投资跨境数据不存在。
6. 公共展示、衍生展示、下载、缓存保存分别核权；本次读取成功不是再分发许可证。

## 发布范围与再使用边界

本目录仅包含七份覆盖/来源清单和说明：不分发 IMF 原始 XML、完整观测值、请求日志、缓存、运行数据库或本地重建脚本。覆盖统计不替代原始金额的许可及语义审核，也不授予源数据再分发权。validation.json 是本次有限检查的记录，不是生产认证。

国家名称和 ISO 标识来源于 iso-codes（LGPL-2.1-or-later）；保留现有[iso-codes版权声明](../../../apps/web/licenses/ISO-CODES-NOTICE.txt)和[许可全文](../../../apps/web/licenses/ISO-CODES-LGPL-2.1.txt)。新增研究字段为本项目覆盖测量和来源索引，不把原始机构数据或第三方名称强行重许可为 Apache-2.0。Kosovo 为明确扩展项，地理分类不代表主权立场。

公开目录只记录数量、覆盖状态、官方入口与方法限制。完整历史、质量、展示授权和生产集成仍待逐源验收；此前已实现的 PIP/TIC 范围不因新增研究行而扩张。
