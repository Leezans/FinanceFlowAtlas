# FinanceFlowAtlas：数据类型与展示设计

编制日期：2026-11-04。本文是拟议展示规范，不表示现有前端已实现或通过测试。来源、证据阶段与实施队列见[总索引](index.md)。

## 1. 设计原则

产品可以提供“全球 → 资产类别 → 国家/地区 → 行业 → 个股”的探索路径，但这不是所有金融数据共同拥有的天然层级。每一级下钻必须有来源支持；缺失的维度应标为“该数据集不支持”，不能用另一类数据悄悄补齐。

先选择指标类型，再选择空间与资产维度。全球视角意味着尽可能广、可比较且可解释的覆盖，不意味着把有限样本包装成全世界。

## 2. 数据类型到展示的映射

| 类型 | 含义 | 推荐展示 | 必须避免 |
| --- | --- | --- | --- |
| 资金流量 | 一段时间内的交易、申购、赎回等；区分流入、流出、净额 | 正负柱图、时间序列；有真实双边数据时使用流向图 | 把持仓变化或上涨市值称为资金流入 |
| 持仓/存量 | 某个时点的持有量或敞口 | 地图着色、排名、配置树图、双边敞口矩阵 | 用动态箭头暗示资金正在移动 |
| 市场活动 | 成交量、成交额、换手等 | 排名、热力图、时间序列 | 把双边交易总额等同于净资金流入 |
| 价格/收益 | 价格、收益率、回报、利差等 | 折线、回报热力图、小多图 | 把价格变化解释为实际投资流量 |

价格、回报、债券收益率与利差应进一步区分。流量要明确总额还是净额。持仓变化可能同时受交易、价格、汇率及其他调整影响；只有存在可靠分解时才能计算派生流量，并明确标注其计算方法。

## 3. 来源到展示的数据契约

每个适配器必须声明以下字段，前端根据这些能力决定可展示视图，而不是从列名猜测含义。

- **来源身份：** 提供者、数据集、序列标识、来源链接、许可或再分发限制。
- **指标：** 类型、子类型、单位、币种、总额/净额、时点值/期间值。
- **时间：** 观测期、原始频率、发布时间、抓取时间、修订版本。
- **覆盖：** 资产范围、报告实体、纳入与排除项目、覆盖说明。
- **地理口径：** 投资者或报告者居住地、发行人居住地、上市交易所所在地、注册地、收入来源地、产品注册地等；不得混用。
- **可用维度：** 国家、对手方国家、资产、行业、具体证券与最低粒度。
- **质量：** 实测/估计/派生、暂定/修订、缺失/保密、方法变更。
- **汇总规则：** 哪些维度可加总、适用分母、分类版本、币种与频率转换方法。

## 4. 全球地图和下钻

1. 全球首页优先展示覆盖可靠、定义一致的指标，地图旁始终提供可搜索排名。
2. 地图只用于有明确地理含义的数据。资产注册地不能默认代表资产实际投资地。
3. 只有来源明确提供起点和终点时才能绘制资金流向。国家净流入不能推断其资金来自哪个国家。
4. 双边持仓属于敞口关系，应使用矩阵或明确标注的静态关系线，不得伪装成当期流量。
5. 线宽对应明确定义的规模；方向与净值正负分开处理，不能因负值擅自交换数据中的关系主体。
6. 全球关系过多时先按地区聚合，或仅显示选中国家的关系；禁止默认堆叠全部连线。
7. 点击国家后保留指标、期间、币种、地理口径和资产范围。需要改变其中任何一项时，明确提示正在切换。
8. 行业与个股下钻只在同一数据契约支持时启用。从宏观资金流切到上市股票涨跌属于“切换数据集与指标”，不属于连续分解。
9. 股票、份额类别和交易所上市代码应有独立标识；多地上市不得重复汇总为不同公司。

## 5. 口径、分母与覆盖

页面保留上下文条，例如：

> 持仓 · 股票 · 发行人居住地 · 数据集覆盖的报告经济体 · 季末 · 美元

每个百分比必须写清分母，例如“占已覆盖资产总额”“占本国已覆盖资产”“占选定资产类别”。筛选后明确选择“相对原始范围”或“相对筛选结果”，不能静默改变分母。

- 部分覆盖不得标为完整全球总量；使用“已覆盖经济体”“已覆盖市场”等准确表述。
- 有可信基准时提供覆盖率；没有基准时仅列已覆盖数量与范围，不编造覆盖率。
- 未分类、其他与残差应保留，不能按比例摊入已命名行业。
- 只有同单位、同期间、同口径且无重叠的观测才能加总。
- 跨国排名默认使用最新共同可比期间；“各自最新值”可作为独立模式，但必须展示各自日期。
- 原始币种与统一币种显示应分开；统一币种需说明汇率来源及转换时间。

## 6. 缺失、陈旧与不可比数据

零值、缺失、未报告、保密、不适用、过期、当前数据集不支持必须分别表示。无数据的国家不能默认填零。

结构断点、分类改变与不同频率不能通过静默插值掩盖。无数据状态应说明原因并推荐真正兼容的视图。演示数据、测试数据必须持续可见地标为演示，不得作为在线数据兜底。

## 7. “每分钟刷新”的四个不同层次

每分钟刷新界面，不代表底层金融观测每分钟产生一次。

| 层次 | 含义 | 展示要求 |
| --- | --- | --- |
| 界面刷新 | 页面重新读取缓存或更新状态 | 可显示“页面每分钟检查更新”，不能标为“每分钟资金流” |
| 来源检查 | 按授权和限额检查来源是否更新 | 显示最后成功检查时间；检查成功不等于数据更新 |
| 数据发布 | 提供者实际发布新观测或修订值 | 显示发布时间和版本，保留修订记录 |
| 观测频率 | 数据代表分钟、日、月、季度或某个时点 | 始终显示原始频率与观测期，禁止虚构更高频率 |

例如季度持仓即使每分钟检查，仍然是季度持仓。分钟行情也不能填充季度跨境流量。建议按数据发布规律调度抓取，使用缓存、增量更新及限流；界面可以每分钟更新检查状态。报价具有分钟粒度但有延迟时，必须单独标示行情延迟。

分别记录并展示必要时间：观测期、来源发布时间、最后成功同步时间。同步失败时保留上次可靠数据并标注状态，不以当前时间覆盖旧观测时间。陈旧判断应依据该数据集的发布周期和已知延迟，而非统一的分钟阈值。

## 8. 响应式体验与可追溯性

- 桌面端采用地图/概览、排名、详情面板及面包屑。
- 移动端默认排名，地图可切换；一次展示一组关系或一个详情，筛选收纳到紧凑面板。
- 关键值不能只在鼠标悬停时出现；支持键盘、屏幕阅读和减少动画偏好。
- 图表标题包含指标与期间；单位、比例尺、覆盖、分母、来源和更新时间可直接找到。
- “关于数据”说明地理口径、排除项、转换方法、许可及限制。
- 表格和下载保留与当前图表一致的筛选条件和元数据。
- 筛选状态可分享；先加载汇总，再按需加载明细。缓存键包含数据集、版本、期间及筛选参数。

## 9. 全球优先的实施顺序

选择数据集时综合评估：地理覆盖、跨国定义一致性、可访问和可再利用性、稳定标识与可复现抓取、发布时间及修订透明度、真实下钻能力、重复计算风险。

1. 建立全球来源目录与上述数据契约，明确每项数据的全球边界。
2. 上线一个可信的全球概览：地图、排名、历史、覆盖和溯源齐备。
3. 实现保持同口径的国家详情，并验证总量和分母。
4. 增加资产类别，但保留各自指标类型，不强行合成单一“全球资金流”。
5. 在来源充分的范围内扩展行业与证券。
6. 取得可验证的双边数据后再增加流向展示。

先建立全球覆盖，不应把单一市场的丰富行情下钻误当作全球覆盖已经完成；也不应为了追求地图完整而拼接不可比指标。

## 10. 验收准则

- [ ] 每个数字可确定指标、单位、期间、地理口径、覆盖与来源。
- [ ] 每条资金流向线都有来源支持的真实双边关系。
- [ ] 资金流、持仓、活动、价格在标签和计算上严格区分。
- [ ] 部分覆盖没有被称为完整全球数据；覆盖率有真实分母。
- [ ] 汇总可对账，差异或残差可解释；重复上市不重复统计。
- [ ] 缺失没有被填成零；演示数据不会伪装为在线结果。
- [ ] 下钻维持原有语义，切换语义有明确提示。
- [ ] 百分比分母明确，筛选变化可解释且可复现。
- [ ] 跨地区比较使用可比日期与定义，例外明确标注。
- [ ] 每分钟检查、来源发布频率和观测频率分别呈现。
- [ ] 同步失败与旧数据状态可见，更新时间不会伪装成观测时间。
- [ ] 手机、键盘和辅助技术用户均能读取关键值及来源。
- [ ] 下载或分享结果保留筛选条件、版本和必要口径说明。
