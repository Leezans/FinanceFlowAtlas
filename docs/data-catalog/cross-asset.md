# FinanceFlowAtlas 跨资产数据源与接入方案

核查日期：2026-11-04。本文依据官方机构或供应商公开文档整理；本轮研究未独立调用 API、签署许可或取得报价。项目已有 PIP F51/TIC 实测摄取与连接器提交，范围和证据见[总索引](index.md)，尚未部署。其余来源的 API 和实现仍待验证。公开可浏览不等于可商业再分发，以下优先级是实施建议。

## 一、指标类型与估算方法

- **交易流量**：某期间的金融交易、基金申购赎回或份额净发行。统计口径不同，仍不可直接相加。
- **持仓存量**：某时点的资产、负债或合约头寸。存量变化包含价格、汇率、重分类等因素，不能直接称为资金流入。
- **交易活跃度**：成交额、成交量、换手率、订单簿等，不等于净流入。
- **价格与收益**：价格、回报、收益率及利差等解释市场表现，不能由涨跌推断投资净流入。

**估算信号是方法标签，不是独立主类型。** 经模型、地址标签、配置权重或其他假设生成的流向代理，应保留原指标类型，并叠加实测/估算/派生标签和方法、覆盖范围。统一定义见[总索引](index.md)。

地理字段必须明确区分：投资者居住地、发行人所在地、基金注册地、资产配置地区、银行营业机构所在地、交易销售台所在地、交易所所在地。不能用其中一个字段冒充另一个；未知地区保留“未知”。

## 二、全球宏观与机构资产网络

### 1. IMF 国际收支 BOP｜P0

- **衡量内容**：居民与非居民之间的期间交易；金融账户可分直接投资、证券投资、其他投资、储备资产等。属于宏观统计交易流量，不是逐笔资金追踪。
- **地理范围**：各经济体对世界其他地区，不能默认存在完整双边起点—终点矩阵。
- **时效**：各国、各系列频率和发布时间不同；接入时逐系列读取元数据，不能统一标为实时。
- **获取**：数据门户下载、SDMX 2.1/3.0 API。API 权限、实际端点及限流尚未实测。
- **权利**：公开访问；商业展示、归属标注及特定数据例外需核查适用条款。
- **展示**：国家净流入/流出时间序列、按工具分类的柱状图、国家分布图。明确资产净获得和负债净发生的符号，避免将原始正负号直接解释为流入流出。
- **来源**：[BOP 数据集](https://data.imf.org/en/datasets/IMF.STA%3ABOP?sc_site=idata)、[IMF API 文档](https://data.imf.org/en/Resource-Pages/IMF-API)。

### 2. IMF PIP，原 CPIS｜P0

- **衡量内容**：跨境证券投资持仓，分股票和基金份额、长期及短期债务证券。属于存量，不是交易流量。
- **地理范围**：持有方经济体与发行人对手经济体；自愿报告及覆盖不全限制整体完整性，不能宣称全球所有机构资金已被覆盖。
- **时效**：年度、半年。
- **获取**：门户下载和 API；需使用现行 PIP 数据集，不应依赖旧 CPIS 路径。
- **权利**：公开访问，商用再展示仍需确认具体条款。
- **展示**：双边持仓矩阵、加权国家网络、某国对外证券投资组合。边代表持仓规模，不应以流动动画暗示实时资金转移。
- **来源**：[PIP 数据集与频率说明](https://data.imf.org/datasets/IMF.STA%3APIP)。

### 3. BIS 属地银行统计 LBS｜P0

- **衡量内容**：国际银行债权和负债；按营业机构居住地统计，未合并口径包含集团内部头寸。经统计断点和汇率调整后的变化仅近似期间流量。
- **地理范围**：报告地区银行营业机构对各对手经济体；报告覆盖、保密和缺失单元应保留。
- **时效**：季度，不是日度跨境资金。
- **获取**：BIS 数据门户、下载文件、SDMX API。
- **权利**：受 BIS permitted-use 条款约束；不应把免费 API 解读为无限再分发授权。
- **展示**：银行国家网络，分债权/负债、存量/调整后变化；用明确标签区分“估计流量”与持仓。
- **来源**：[LBS 方法与范围](https://data.bis.org/topics/LBS)、[API 文档](https://stats.bis.org/api-doc/v2/)、[使用条款](https://data.bis.org/help/legal)。

### 4. 美国财政部 TIC｜P0

- **衡量内容**：美国居民与外国居民证券交易和证券持仓，另有银行、非银行及衍生品相关数据。交易和持仓需分开处理。
- **地理范围**：以美国为中心；国别可能反映交易对手、托管机构或管理机构所在地，而非最终受益所有人。
- **时效**：证券主要为月度，其他组成部分有月度/季度；使用实际发布日期而非观察期结束日作为可获得时间。
- **获取**：官方表格和归档下载；本次未验证通用稳定 REST API，建议文件适配器并监控格式变化。
- **权利**：官方公开数据；上线前核对使用说明和归属要求。
- **展示**：美国中心的国别证券净交易、国别持仓、工具分类；显著提示托管偏差，不标为最终国家资金来源。
- **来源**：[TIC 入口](https://home.treasury.gov/data/treasury-international-capital-tic-system/)、[数据归档](https://home.treasury.gov/archives-of-tic-monthly-data-releases)、[托管偏差说明](https://home.treasury.gov/system/files/136/Press-notice-TIC-for-Sep-2024.pdf)。

### 5. ECB 国际收支与国际投资头寸｜P1

- **衡量内容**：欧元区居民与非居民的交易和头寸；各系列国别与部门细分不同。
- **时效**：月度、季度。
- **获取**：ECB SDMX 2.1 REST 服务；支持按更新时间获取修订，实际调用未验证。
- **权利**：公开统计服务，按适用再使用条款处理。
- **展示**：欧元区资本交易趋势和工具/部门切片；欧元区总量与成员国不能直接相加，需防止重复计算。
- **来源**：[BOP/IIP 说明](https://www.ecb.europa.eu/stats/balance_of_payments_and_external/balance_of_payments/html/index.en.html)、[SDMX 获取说明](https://data.ecb.europa.eu/help/getting-data-web-services-sdmx-0)、[修订增量参数](https://data.ecb.europa.eu/help/api/data)。

### 6. ECB 投资基金统计｜P1

- **衡量内容**：基金资产负债的存量与交易数据。基金所在地不等于投资者所在地，也不等于底层资产敞口所在地。
- **时效**：需逐系列核对月度/季度频率及细分覆盖。
- **获取**：ECB 数据门户及 SDMX API。
- **权利**：公开访问，具体商用展示条款需核查。
- **展示**：基金类型交易柱状图、资产配置结构与存量趋势，保留金融工具及会计口径。
- **来源**：[ECB 投资基金统计](https://www.ecb.europa.eu/stats/financial_corporations/investment_funds/html/index.fi.html)。

### 7. 美联储金融账户 Z.1｜P1

- **衡量内容**：美国部门金融交易、资产负债、工具持仓与部分发行方—持有方关系，是部门金融账户而非全球投资者跟踪。
- **时效**：季度，通常在季末后约十周发布；底层明细可晚于主体发布。
- **获取**：发布页 CSV、历史数据下载及 FRED 接入路线。DDP 页面提示 2026 年 11 月 9 日当周将移除 Build Your Package，随后逐步退役；不应把旧 DDP 界面作为新系统长期依赖。
- **权利**：官方公开统计，核对归属与具体来源限制。
- **展示**：部门—工具结构、金融交易与持仓双视图；仅在关系数据支持时画桑基图，不能由边际总量凭空推导双边流向。季调年率与实际季度金额必须区分。
- **来源**：[Z.1 发布页](https://www.federalreserve.gov/releases/z1/default.htm)、[DDP 与迁移通知](https://www.federalreserve.gov/datadownload/Choose.aspx?rel=Z1)。

## 三、ETF 与跨资产基金流量

### 8. ICI ETF 净发行｜P1，需先确认展示许可

- **衡量内容**：ETF 总发行减赎回；周度是估算，月度为实际收集数据。与二级市场 ETF 成交额不同，也不等于现金方式申购的金额。
- **分类范围**：按基金投资目标分类；“全球股票”等分类不能确定投资者来源国家。
- **时效**：周度估算和月度实际数据，可能修订。
- **获取**：公开发布页及 XLS 文件；本次未验证官方生产 API。
- **权利**：页面明确要求通过 permission request form 申请使用或复制 ICI 材料；需落实公共展示许可。
- **展示**：基金类别净发行柱状图和热力图，明确“估算/实际”和修订时间，不用类别名称构造国别资金箭头。
- **来源**：[ICI 周度 ETF 数据与许可提示](https://www.ici.org/research/statistics/etfs/weekly-estimated-etf-net-issuance)、[指标说明](https://www.ici.org/research/stats/etf_flows)。

### 9. EPFR｜P2，商业采购

- **衡量内容**：覆盖基金的申购赎回、资产规模与配置；Country Flows 结合基金流量和国家配置生成估算，并非直接观察的跨境交易。
- **覆盖**：全球注册基金的样本，不代表所有全球资本；不同频率覆盖可能不同。基金注册地、份额类别和配置国应分别存储。
- **时效**：供应商产品概览列示 Fund Flows 日度/周度 T+1、月度 T+16；该说明来自历史产品资料，需在采购时确认现行 SLA 与 Country Flows 的独立延迟。
- **获取**：商业 API 和授权数据交付，具体端点及完整覆盖未验证。
- **权利**：报价制；须单独取得外部展示、派生图表、历史保存及数据下载权利，不能用个人终端订阅替代产品许可。
- **展示**：资产类别/地区/行业配置流量热力图，区分“基金实际净申赎”与“配置估算地区流量”。
- **来源**：[EPFR 官方产品概览](https://epfr.com/wp-content/uploads/2023/09/EFPR-Product-Overview.pdf)、[基金流量与国家配置方法说明](https://epfr.com/wp-content/uploads/2022/05/Fund_Flows_as_Country_Allocator3.pdf)。

## 四、期货与外汇

### 10. CFTC COT / Traders in Financial Futures｜P0

- **衡量内容**：不同交易者类别的期货和期权未平仓头寸；TFF 可用于外汇、利率和股指等金融期货。不是资金净流入，类别变化也可能由交易者重分类引起。
- **地理范围**：合约与受报告市场，不披露可用于国家资金来源地图的投资者居住地。
- **时效**：通常周二观察、周五发布；节假日可能调整，必须分别保存观察日和实际发布时间。
- **获取**：官方公开报告环境支持 API、CSV 等下载。
- **权利**：公开访问，按官方使用要求及归属处理。
- **展示**：多/空/净头寸、周变化、历史分位；合约数量转名义敞口须带合约乘数，不能称为投入现金。
- **来源**：[公开报告 API 指引](https://publicreporting.cftc.gov/stories/s/COT-Help/p2fg-u73y/)、[发布日期表](https://www.cftc.gov/MarketReports/CommitmentsofTraders/ReleaseSchedule/index.htm)。

### 11. CME 期货市场数据｜P2

- **衡量内容**：成交、价格、订单簿、结算等；成交量和未平仓量需确认具体产品授权。属于交易活跃度和敞口，不是投资者国别资金流。
- **时效/获取**：实时和历史 REST、WebSocket 或云交付，频率与延迟取决于产品和许可。
- **权利**：商业许可；实时、延迟、历史、显示、非显示及下载分发可能分别计费。未取得报价，不给出虚构价格。
- **展示**：合约成交活跃度、未平仓变化、期限结构和流动性面板；避免把未平仓名义价值当作现金流入。
- **来源**：[官方数据服务入口](https://www.cmegroup.com/tools-information/webhelp/data-services-portal/Content/GettingStarted.html)、[历史数据分发许可说明](https://www.cmegroup.com/market-data/distributor/files/cme-group-data-licensing-policy-guidelines-historical-information-distribution.pdf)。

### 12. BIS 外汇三年调查｜P1，结构性背景

- **衡量内容**：外汇即期及场外衍生品成交额，分币种、工具、对手类别和销售台所在地。是成交规模，不是方向性资本流。
- **时效**：每三年调查四月份平均日成交，不应用作实时指标。
- **获取**：门户、表格下载及 BIS API，具体可用系列需验证。
- **权利**：BIS 使用条款。
- **展示**：外汇交易中心份额地图、币种对网络；明确地理依据是销售台，标出调查年月及去重口径。
- **来源**：[调查范围和方法](https://data.bis.org/topics/DER)、[2025 调查结果入口](https://www.bis.org/publications/triennial-central-bank-survey-foreign-exchange-and-over-the-counter-otc-derivatives-markets-2025)。

### 13. CLS FX Flow｜P2

- **衡量内容**：基于 CLS 所观察交易及模型识别的做市商/价格接受者方向，涉及即期、掉期、远期。是样本和算法信号，不是完整全球外汇资金普查。
- **地理范围**：币种与参与者类型；不能据此断言最终投资者国籍、国家资本流或央行干预。
- **时效/获取**：商业数据集；具体频率、延迟、币种覆盖和交付方式待供应商确认。公开月度交易活动摘要不等于完整 FX Flow 数据授权。
- **权利**：报价及再分发许可待核实。
- **展示**：币种对方向压力、工具和期限切片，附模型与覆盖标签，不放入“实际跨境资金流”总量。
- **来源**：[CLS FX Flow 方法](https://www.cls-group.com/products/data/clsmarketdata/fx-flow/)、[公开交易活动摘要](https://www.cls-group.com/Products/Data)。

## 五、债券

### 14. FINRA TRACE / Fixed Income API｜P1 聚合，P2 逐笔

- **衡量内容**：报告的场外债券成交价格、收益率、成交量及市场聚合指标。成交活跃度不是债券净资金流入。
- **地理范围**：证券和报告交易市场，不提供完整最终投资者国别归属。
- **时效**：API 聚合数据包括周度美国国债成交等；逐笔、延迟、历史产品各有独立规则。不要将某个 TRACE 产品的权限和频率推广到所有债种。
- **获取**：FINRA Developer 平台聚合接口与 TRACE 专门接口分开；后者不是同一 API 平台。
- **权利**：官方概览说明市场聚合可免数据费但需用户协议；逐笔实时、专业显示和增强历史等涉及协议及费用。具体当前价格与条款未验证。
- **展示**：债券流动性、成交量、收益率和市场宽度；保留成交规模上限、撤销更正和交易商间重复处理规则。
- **来源**：[API 产品区分](https://developer.finra.org/docs)、[TRACE 数据与协议说明](https://www.finra.org/sites/default/files/TRACE_Overview.pdf)。

## 六、加密资产

### 15. Glassnode｜P2

- **衡量内容**：涉及标记交易所地址的链上转账、余额及实体调整指标。标签与聚类会修订；充值不等于卖出，提现不等于买入。
- **地理范围**：链、资产、交易所/实体；交易所总部不能作为用户所在国家。
- **时效/获取**：API 资产与频率受订阅权限约束，具体覆盖待验证。部分 Point-in-Time 指标提供不回写历史的版本，可减少回测前视偏差。
- **权利**：需商业 API 与外部显示许可核查，不假定终端订阅自带再分发权。
- **展示**：交易所充值/提现净额、链上持仓与实体分布，提示内部钱包迁移和标签修订；不构造无依据的国家地图。
- **来源**：[交易所地址透明度说明](https://docs.glassnode.com/further-information/exchange-data-transparency-notice)、[Point-in-Time API](https://docs.glassnode.com/basic-api/endpoints/pit)。

### 16. Coin Metrics｜P1 原型研究，P2 商业产品

- **衡量内容**：链上网络指标、市场数据、交易所/矿工流量估计；地址识别依赖种子地址和启发式聚类，存在覆盖与方法局限。
- **时效/获取**：REST API 和覆盖目录；不同资产—指标组合频率不同，应查询目录，不能统一承诺逐块或实时。
- **权利**：Community 数据明确采用 CC BY-NC；免费接口不能直接当作商用产品数据源。商业使用需 Pro 合同与相应展示权利。
- **展示**：链上转移、交易所流量和市场活动面板；把转账与交易成交区别开，无可靠地理归属时显示未知。
- **来源**：[覆盖与许可说明](https://docs.coinmetrics.io/service-and-support/coverage)、[方法 FAQ](https://docs.coinmetrics.io/service-and-support/faqs)。

### 17. DefiLlama｜P1 研究，许可确认后上线

- **衡量内容**：稳定币供应、链级分布、跨链桥转移等。桥转移是链间转移，不是国家资本流；TVL 变化或稳定币供应变化不能无条件解释为净投资流入。
- **时效/获取**：API 目录及按端点区分的计划；桥数据有计划相关路径。实时性、覆盖链、完整历史、最终性和修订行为需实测。
- **权利**：免费可访问端点和收费计划分别确认商用、图表和数据下载权；本次未取得明确再分发授权。
- **展示**：链到链桥转移桑基图、稳定币供应与链占比；处理铸造/销毁、封装资产、内部迁移与重复计量。
- **来源**：[官方 API 文档](https://api-docs.defillama.com/)、[官方端点仓库](https://github.com/DefiLlama/api-docs/blob/main/llms-pro.txt)。

## 七、阶段安排与上线门槛

以下为本专题的价值排序，跨专题执行顺序以[总索引的接入队列](index.md#4-统一的优先级与接入队列)为准。本文主体来源为 V1 官方产品/说明发现；PIP F51/TIC 的已有实测和实现另见总索引，不扩大至整个产品或生产运行。历史产品资料与当前 SLA 的区别在对应条目说明。

### P0：先建立可解释的官方数据骨架

接入 IMF BOP、PIP、BIS LBS、TIC、CFTC。先实现国家宏观交易、跨境持仓网络、银行调整后变化、期货头寸四个独立模块。它们频率不同，不构造一个混合“全球实时资金净流入”数字。

### P1：补齐区域、基金、债券及链上背景

增加 ECB、Z.1、BIS 外汇调查；完成许可确认后接入 ICI 和 FINRA 聚合。加密数据可先用于非商用研究和验证，不因原型可访问就自动发布到商用站点。

### P2：按用户价值采购更高频和更广覆盖

优先评估 EPFR 的基金类别/地区流量，再根据产品需求选择 CLS、CME、TRACE 逐笔、Glassnode 或 Coin Metrics Pro。采购不是为了制造“全球所有资金实时可见”的承诺，而是补足明确的资产、频率和方法缺口。

### 每个来源上线前必须完成

1. 验证 API/文件实际可用性、限流、历史深度、修订、缺失与错误处理。
2. 保存原始文件与观察期、发布时间、抓取时间、修订版本，避免回测前视偏差。
3. 元数据至少包含：指标类别、单位、币种、汇率转换方式、总额/净额、地理依据、覆盖宇宙、保密/缺失状态、估算方法和显示授权。
4. 明确 API 内部使用、公共图表、派生数据、底层下载、缓存、历史留存及终止合同后的处理权限。
5. 界面分开“交易流量 / 持仓 / 活跃度 / 价格与收益”，并另外标记实测/估算/派生；显示“数据截至”而非仅显示最近抓取时间。
6. 只对可比较的频率、单位和口径做聚合；不同体系可能覆盖同一笔资金，不跨体系求和。

## 八、明确未完成或不应承诺的部分
