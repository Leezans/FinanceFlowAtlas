# A 股行业→个股树图：来源合约一页说明

**状态：仅可复用校验器与渲染器，没有行情源、API、定时采集或生产数据。** 当前托管 TIC 页面未改动。本目录测试数据全为合成记录，仅测试文件使用，不能替代来源批准。

## 输入与展示许可边界

可信服务端先完成来源访问、预定私用展示权限、单位和方法核验，再调用 `validateAShareSnapshot(input, { now, expectedPayloadSha256? })`。成功返回带类型标记的 `ValidatedAShareSnapshot`；`AShareTree` 只接收该类型或 `null`。`null` 仅显示未接入，不制造区块。

`display_rights: verified_private_display` 是服务端证据标记，不授予权限，也不是浏览器独立法律审核。每个来源保留 CN_A_SHARE 市场标识、数据版本、链接、权限依据及核验时间。未知标记拒绝。这只是防误用的一致性校验，不能充当真正的许可门禁：来源使用与展示权限必须在可信服务端实际落实，不能靠客户端组件或自填字段绕过。代理指标另需同一来源的方法文档、版本、定义、局限及展示依据。载荷 SHA-256 由适配器对原始/规范化载荷建立，前端不自证哈希；如传入可信预期值，校验器检查一致性。不是用哈希字段替代来源批准。

## 最小完整快照（严格拒绝未知字段）

- 身份：`contract_version: ashare-tree/1`、`payload_sha256`、`adapter_version`；`universe` 的 ID、日期与预期证券数（未知可为 null）。不宣称全市场覆盖。
- 日期：一个 `trade_date`、一个明确快照频率 `frequency`、一个交易 `session`、`timezone: Asia/Shanghai`、抓取时间与明确陈旧阈值。观测/抓取先后、东八区交易日期、同一 session 均检查。交易日历可为 null；只有提供可信适配器核验标记、版本、日期和交易日集合时才按该集合验证。否则界面明确日历未核验，不能宣称独立验证交易日。
- 行业：分类 ID、版本、层级、`exclusive: true`、as-of、生效日期、来源与行业节点。本版只支持单层行业→股票：每个行业节点的 `parent_id` 必须为 null，任何非 null 父级都拒绝，不能静默平铺多级行业。若供应商给出多级分类，可信适配器必须先选择并验证一个互斥层级，输出该层级；本组件不推导父行业成分。每只证券只有一个行业 ID 或 null（未分类）。行业 as-of 必须对应观测日期，不能静默套用当前分类到历史。重叠分类拒绝用作可加总树图。
- 证券：`MIC:六位代码` ID、MIC（XSHG / XSHE / XBEI）、名称、普通 A 股类型、上市/停牌/退市状态、上市日期、参考来源/日期、归属日期和概念标签。代码不脱离交易所识别；退市记录不进入面积。
- 观测：证券 ID、metric、原始值、单位、reported/missing 状态与缺失原因、交易日/session、观测/抓取时间、来源发布时间（未知为 null）、调整口径、来源 ID。单证券/指标不允许重复；同一可比较指标的已报告行必须使用相同 source_id 和 adjustment，拒绝混提供方/方法口径。reported zero 与 missing 严格分离。

## 面积和颜色，不混为“资金”

面积只可选择实际提供并验证的 `market_cap`、`float_market_cap` 或 `turnover`，统一人民币；输入显式声明 `CNY`、`CNY_10K` 或 `CNY_100M`，仅换算一次。不得推算缺失流通市值。零面积单列；缺面积不补零；未分类保留。

默认颜色优先 `price_return`，单位为 **百分比数值**（2 表示 2%，不是 0.02）。另可选择 `provider_order_flow_proxy`，但只有提供订单分类方法与许可证据且存在观测时才开放。此代理可描述市场内部供应商定义的订单分类净额，**不是市场真实净增资金、净投资流量或财富变化**；不由价格、成交额或市值差分推导。颜色缺失用独立灰色，报告零用中性色。红正/绿负可切换而不改数值。

行业→成分股面包屑、交易所限定搜索、概念筛选、证券证据可用。概念可能重叠，只作为去重后的证券筛选，绝不重复分组累加市场份额。面积分母只为当前有效筛选的已报告非零面积值之和。

## 集成前剩余门槛

真实供应商与展示权限、证券范围、行业互斥性、实际单位/缩放、方法版本、交易日历和时间样本仍需研究核验。本组件不抓取、不轮询、不保存历史；调用者控制缓存与时间刷新。陈旧快照保留并警告，不伪装最新。接入或发布前，需用批准的真实样本再做适配器、覆盖及浏览器验证。
